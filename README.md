## 🌟 Three Primary Views (Feature 3)

### 1. Movies View
- Browse all MCU titles with release year, runtime, and watched status.
- Add new movies with validation constraints (release year 1800–2100, runtime 1–300 mins).
- Edit prerequisites in an interactive modal with instant **`409 CIRCULAR_DEPENDENCY`** visual error banners.
- Quick toggle button to mark movies as watched or unwatched.

### 2. Rewatch Plan View
- Select target movie (defaults to *Avengers: Doomsday*).
- Interactive rewatch progress bar (e.g. `"4 of 7 watched - 57%"`).
- Dynamic remaining watch time counter in minutes and hours across unwatched prerequisites.
- Sequential numbered linear roadmap generated by backend topological sorting.

### 3. Watch-Party Booking View
- Select cinema and configure group size (1 to 10,000 seats).
- **Challenge Test Presets**: One-click test buttons for instant assessment verification:
  - `[1, 3, 4]` for $6 \rightarrow$ `2 bundles: 3 × 2`
  - `[2, 5]` for $11 \rightarrow$ `4 bundles: 5 × 1, 2 × 3`
  - `[6, 9, 20]` for $44 \rightarrow$ `4 bundles: 20 × 1, 9 × 2, 6 × 1`
  - `[4, 6]` for $7 \rightarrow$ `Not possible`
- Exact bundle breakdown breakdown or clean impossibility notification.
- Modal to register custom cinema partners.

## ⚡ Setup & Run

### 1. Environment Variable
Create a `.env.local` file (or relies on default `http://localhost:5000/api`):
```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

### 2. Install & Start
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Docker Run (Bonus)
```bash
docker build -t doomsday-frontend .
docker run -p 3000:3000 doomsday-frontend
```
